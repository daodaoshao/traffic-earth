Traffic Earth · Architecture

流量地球 架构设计

在一个缓慢自转的 3D 地球上，实时展示家庭或办公局域网的流量流向哪里、有多少、属于什么类别。本文描述当前实现（v0.1）的技术栈、模块划分、数据管线和关键取舍。

01定位与目标

流量地球是一个可以自行部署的开源应用。它从局域网出口路由器读取连接表，把每条连接定位到地球上的城市，再按设备、目标、地区和类别做实时统计。

  • 主数据源是 OpenWrt 路由器。OpenWrt 及其衍生固件（ImmortalWrt 等）装机量大，产品不应依赖任何代理软件。
  • mihomo 是可选增强。路由器上运行 mihomo（Nikki、OpenClash）时，可以补充域名、规则和代理出口；使用 fake-ip 模式时必须接入。
  • 只读接入，数据不出本地。路由器端只装一个只读插件；除了每月下载一次 IP 地理库，不向任何外部服务发送数据。
  • 界面完整双语，演示友好。中文和英文互不混杂；提供演示模式，用于录屏和公开展示。

不做的事：不做流量控制和拦截，不抓包、不解析载荷，不做公网多租户托管。

02总体架构

系统分三层：路由器侧的数据源、一个常驻的后端服务、浏览器里的渲染端。后端通过局域网拉取数据，计算速率并打上地理位置和类别，每秒把一帧聚合结果推给所有打开的页面。

04数据源与接入

OpenWrt：为什么要装一个插件

OpenWrt 已经有几种读取连接表的途径，但实测都满足不了需求。这些数字来自一台有 2000–2600 条连接的家用路由器：

途径结论原因
luci.getConntrackList不够用只给每条连接的上下行合计字节，无法区分上传和下载。
rpcd file read 读 /proc不可用procfs 文件大小报告为 0，只能读回第一页，约 4 KB。
rpcd file exec + cat不可用输出上限约 256 KB，而完整连接表就有 570 KB。
自带 ucode 插件采用在路由器上解析连接表，分开上下行，丢掉纯内网连接，压缩成数组：1176 条约 136 KB，单次约 0.3 秒。

一行命令接入

配置中心为每次接入生成一个一小时内有效的令牌。用户在路由器上执行：

wget -qO- 'http://<服务地址>:8097/api/openwrt/setup.sh?t=<令牌>' | sh

脚本只做三件事，卸载命令在配置中心里提供：

  1. 写入只读插件 /usr/share/rpcd/ucode/traffic-earth.uc，以及 ACL 文件 /usr/share/rpcd/acl.d/traffic-earth.json；
  2. 建立专用登录 rpcd.traffic_earth，密码是服务端生成的随机串（md5crypt 哈希），权限只包括插件的 info / snapshot 和 luci-rpc 的 getHostHints / getDHCPLeases / getNetworkDevices；
  3. 如果 nf_conntrack_acct 没开就打开它，然后重启 rpcd。

OpenWrt 适配器

  • 轮询：默认每 2 秒调用一次 traffic-earth.snapshot。如果单次调用耗时超过间隔的 1/4，就自动拉长间隔，避免拖累繁忙的路由器。
  • 方向判断：源地址属于本地（私网、路由器自身地址、LAN 侧 IPv6 前缀）的是出站连接；否则是入站连接，再根据 DNAT 后的回包地址找到真正被访问的内网主机。
  • WAN 总量：从默认路由识别 WAN 网卡，排除 tun、WireGuard 等代理隧道，用网卡收发计数作为吞吐的真实值。
  • 设备目录：每 60 秒从 luci-rpc 拉取主机名、DHCP 租约和 IPv6 邻居，以 MAC 地址作为设备身份，把同一台设备的 IPv4 和多个 IPv6 地址合并到一起。

mihomo 适配器

订阅 ws://<控制器>/connections?interval=1000，每秒得到一份完整快照，包含域名（host / sniffHost）、命中的规则和代理链。断线后按指数退避重连，最长间隔 30 秒；10 秒收不到数据视为断线。

05合并与去重

同一台路由器同时接入 OpenWrt 和 mihomo 时，一条被代理的连接会在两边各出现一次。合并的原则是：出站连接以 mihomo 为准，入站和绕过代理的连接以路由器为准。路由器侧的出站连接满足下面任一条件就跳过：

条件说明
回包来自路由器自己的地址连接被本机透明代理（REDIRECT / TPROXY）接管。在 fake-ip 模式下，这类连接的目标地址都是 198.18.x.x，无法定位。
设备地址 + 源端口与 mihomo 中的连接相同同一条连接，按 mihomo 的数据计入。
由路由器自身发起大部分是 mihomo 连往代理节点的外层连接，计入会重复。
曾被 mihomo 认领过认领关系会一直保留：mihomo 关闭连接后，conntrack 里还会残留一段时间，否则整条连接的累计字节会被再算一次。
关联的 mihomo 尚未就绪启动阶段或 mihomo 断线时无法判断归属，暂不计入出站连接。
读取 procfs 会漏条目。连接表在读取过程中发生变化时，/proc/net/nf_conntrack 的分块遍历会漏掉一些条目。因此一条连接要连续 3 次快照都缺席才判定为关闭；只有最近 3 次快照里从未出现过的连接，才把它的累计字节全额计入。

分类

17 个类别：视频、社交、通讯、AI、开发、游戏、音乐、购物、资讯、下载更新、云与 CDN、智能家居、系统服务、广告追踪、外部访问、内网、其他。判断顺序是：

  1. 域名后缀，最长匹配优先（比如 music.163.com 优先于 163.com）；
  2. 目标 ASN（比如 13335 Cloudflare 归为云与 CDN）；
  3. 端口（比如 53 归为系统服务，3478 归为通讯）；
  4. 入站连接统一归为「外部访问」。

速率口径

标题栏的吞吐取自 WAN 网卡计数，是真实的线路流量。各行速率来自连接级差分，加起来可能和 WAN 总量有出入：代理封装大约有 4% 开销，两个数据源的采样时间也不完全对齐。

08实时帧与接口

实时帧（WS /api/live，每秒一帧）

一帧包含总量、数据源状态、聚合行、本帧用到的地点、设备名和今日计数。聚合行是帧的主体，字段名都很短，以控制体积：

字段含义
s数据源 ID
d设备键：MAC 地址，没有 MAC 时用 IP，路由器自身为 router
h可注册域名；没有域名时是对端 IP
p地点键（经纬度保留一位小数），对应帧内 points
c / x / i类别 / 出口节点（直连为 DIRECT）/ 是否入站
u / w流出 / 流入速率，单位字节每秒
n / o连接数 / ASN 所属组织（仅无域名的行）

REST 接口

方法与路径用途认证
GET /api/state是否已初始化、是否已登录无
POST /api/setup首次初始化：数据源、位置、管理员密码仅限未初始化时
POST /api/login · /api/logout登录、登出（每个 IP 每分钟最多尝试 5 次）无
GET /api/meta类别和颜色、家的位置、显示设置需要
GET · PUT /api/settings读取和修改配置（位置、保留时长、写盘间隔、画质等）需要

POST /api/sources/test测试连接，返回结构化的结果初始化期间无需

飞线的视觉编码

方向
光点按数据的主要流向移动：以下载为主时流回家，以上传为主时流出。反向流量要多出 30% 才会掉头，避免来回闪烁。
粗细与速度
按对数比例分成 6 档；只有档位变化时才重建几何体，平时不触发重绘开销。
颜色
类别颜色；外网主动连进来的连接用青色。

流畅度设计

  • 固定槽位：面板高度固定，图例 8 行、排行各 12 行、设备 8 行，内容变化时只改文字，不改变布局。
  • 平滑数值：速率先做指数平滑再显示；排行每 3 秒才重排一次；进度条、环形图和标签淡入都由动画循环逐帧逼近目标值。
  • 避免高开销效果：动态画布上方不使用毛玻璃和混合模式；标签用 transform 定位，先统一读取尺寸再统一写入。
  • 自动画质：后台和卡顿时段不计入帧率统计。连续低于 30 帧时降档，恢复后自动升档；降档时补偿线宽。

11配置中心与安全

  • 必须登录：页面能看到网络里每台设备的访问记录，所以首次初始化时必须设置管理员密码，或者通过环境变量 ADMIN_PASSWORD 预设。
  • 密钥不出服务端：路由器密码和 mihomo secret 在库里加密存储，接口永远不会把它们返回给浏览器，界面上只显示「已设置」。
  • 最小权限：路由器上的专用账号只能调用 5 个只读方法，不能执行命令，也不能读写文件。
  • 热生效：修改数据源后对应的适配器会立即重建，不需要重启服务。
  • 审计：初始化、数据源增删改、配置修改、改密码都会写入审计日志。

12国际化

界面上的每一处文字都经过翻译函数；切换语言时整个视图重建。服务端从不返回文案，只返回错误码和参数，由浏览器按当前语言渲染。

  • 国家名：由浏览器的 Intl.DisplayNames 按语言生成。
  • 城市名：DB-IP Lite 只有英文。中文界面使用内置对照表（约 250 个城市、250 个省或州）；查不到时退回「国家 · 省」，再退回只显示国家，不显示英文。
  • 运营商名：属于数据，只出现在悬停提示里；中文界面下常见运营商会翻译，其余不显示。
  • 路由器脚本：提示语使用生成命令时的界面语言。

14已知限制与规划

已知限制

  • 只接 OpenWrt 时看不到域名，类别只能靠 ASN 和端口推断。
  • 免费地理库只精确到城市；任播地址（1.1.1.1、各类 CDN）的位置可能不合常理。
  • 开启硬件流量卸载时，被卸载的连接计数可能更新不及时。
  • 连接表每次整张拉取；连接数达到几万条的网络，轮询会自动放慢。
  • 今日分类只有全网口径，按设备筛选时无法显示该设备的今日分类。
